# MyScore — ระบบบันทึกคะแนนสำหรับครู

ระบบเว็บ HTML/CSS/JavaScript (vanilla) เชื่อมต่อ Firebase (Authentication + Firestore)

## อัปเดตในเวอร์ชันนี้

- **สร้างวิชาครั้งเดียว หลายห้อง**: ตอนสร้างรายวิชา เลือกได้ว่าจะ "ระบุจำนวนห้อง" (ระบบสร้างห้อง 1,2,3... ให้อัตโนมัติ) หรือ "พิมพ์เลขห้องเอง" (เช่น `1,2,3` หรือ `1-5` หรือ `ม.6/1, ม.6/2`)
- **โครงสร้างคะแนนใช้ร่วมกันทุกห้อง**: ตั้งสัดส่วนคะแนนเก็บ/กลางภาค/ปลายภาคที่ระดับวิชา ไม่ต้องตั้งซ้ำทุกห้อง
- **นักเรียน/คะแนน/รายงาน แยกตามห้อง**: ในหน้ารายวิชาจะมีแถบเลือกห้อง (room pills) ด้านบน สลับห้องได้ทันที เพิ่มห้องเพิ่มเติมภายหลังได้ที่ปุ่ม "+ เพิ่มห้อง"
- **ดีไซน์เอิร์ธโทน มินิมอล responsive**: ปรับชุดสีเป็นโทนธรรมชาติ (เขียวมอส/สีดิน/สีทราย) พร้อมเมนูแบบ hamburger สำหรับหน้าจอมือถือ (สลับ sidebar เป็น drawer เลื่อนเข้า-ออกได้จริง)
- **สันปกหนังสือ + ปกหนังสือ**: เมนูข้างเป็นสันปกสีเขียวเข้มเรียบ ทันสมัย โลโก้อยู่บนป้ายชื่อและแสดงตลอด (แม้ย่อเมนู/เปิดลิ้นชักบนมือถือ) ส่วนหน้าแรกเป็นปกหนังสือสมัยใหม่ (ตัวอักษรหนา + รูปทรงเรขาคณิต + ตัวเลขสรุป) แล้วกราฟ/รายวิชาอยู่ในหน้ากระดาษด้านล่าง — สไตล์อยู่ใน `css/style.css` (ย้อนกลับไปแบบเดิมให้ใช้ git ไม่มีบล็อกสำรองในไฟล์)

- **ดีไซน์ One UI (ขาว + เอิร์ธโทน)**: มุมโค้งใหญ่ หัวเรื่องใหญ่ชิดซ้าย การ์ดขาวบนพื้นอุ่น ปุ่ม/แท็บทรงแคปซูล — อยู่ใน `css/style.css` (ย้อนกลับไปแบบปกหนังสือให้ใช้ git)

- **One UI 9 + โหมดมืด**: สีหลักฟ้า One UI `#3E91FF` บนพื้นเทากลาง ๆ โหมดมืดพื้นดำสนิท สลับได้ที่ ตั้งค่า → ธีม (ตามระบบ / สว่าง / มืด) จำค่าไว้ในเครื่อง ตั้งค่าอยู่ใน `js/theme.js` และบล็อก "One UI 9" ท้าย `css/style.css` (ตัวแปรสีทั้งหมดอยู่ที่ `:root` และ `:root[data-theme="dark"]`)

- **วิดเจ็ตแบบ One UI**: การ์ดหน้าแรก ทางลัด รายวิชา ห้องเรียน และความคืบหน้า เป็นการ์ดสีพาสเทลต่อหมวด ไอคอนทรงสควิร์เคิลสีสด (สีมาจากตัวแปร `--w` ของแต่ละการ์ด และชุด `--hue-*` ใน `:root`) บล็อก "วิดเจ็ตแบบ One UI" ท้าย `css/style.css`

- **ธีมตาราง/กราฟ ม่วง·ฟ้า·เขียว·ขาว**: หัวตารางทุกแบบไล่สีม่วง→ฟ้า, กลุ่มคะแนน เก็บ=ฟ้า / กลางภาค=เขียว / ปลายภาค=ม่วง, กราฟแท่งไล่ม่วง→ฟ้า→เขียว, กราฟเส้น สูงสุด=เขียว เฉลี่ย=ฟ้า ต่ำสุด=ม่วง, สีระดับชั้น (`LEVEL_COLORS` ใน `js/utils.js`) และโดนัทใช้ชุดสีเดียวกัน — ตัวแปร `--viz-*` ในบล็อกท้าย `css/style.css`

## โครงสร้างข้อมูลใหม่ (Firestore)

```
users/{uid}/courses/{courseId}                    ข้อมูลวิชา (รหัส/ชื่อ/ระดับชั้น/ภาคเรียน) + โครงสร้างคะแนน
  /assessments/{id}                                รายการคะแนนเก็บ/กลางภาค/ปลายภาค (ใช้ร่วมกันทุกห้อง)
  /settings/grading                                เกณฑ์เกรด (ใช้ร่วมกันทุกห้อง)
  /sections/{sectionId}                            ห้องเรียนแต่ละห้อง { room, order }
    /students/{id}                                 นักเรียนของห้องนั้น
    /scores/{studentId}                             คะแนนของนักเรียนในห้องนั้น
```

firestore.rules เดิมเป็น wildcard recursive อยู่แล้ว ครอบคลุมโครงสร้างใหม่โดยไม่ต้องแก้ไข

## วิธีติดตั้ง

1. **ใส่ค่า Firebase ของคุณ**
   เปิดไฟล์ `js/firebase-config.js` แล้วแทนที่ค่าด้วย config จริงจาก
   Firebase Console → Project settings → General → Your apps → SDK setup

2. **เปิดใช้ Google Sign-In**
   ไปที่ Firebase Console → Authentication → Sign-in method → เปิดใช้งาน Google

3. **สร้าง Firestore Database**
   ไปที่ Firebase Console → Firestore Database → Create database
   จากนั้นนำกฎใน `firestore.rules` ไปวางในแท็บ Rules (บังคับให้ครูแต่ละคนเข้าถึงได้เฉพาะข้อมูลของตัวเอง)

4. **รันเว็บ**
   เปิด `index.html` ผ่าน local server ใดก็ได้ (Firebase Auth ต้องรันผ่าน http/https ไม่ใช่ file://)
   เช่น `npx serve .` หรือใช้ Firebase Hosting: `firebase deploy`

1. assets/banner.webp หนัก 2.3 MB

banner-still.webp (20 KB) ใช้แทนแบนเนอร์เคลื่อนไหวเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว, banner-sm.webp ใช้บนมือถือ
ทางแก้: ลดเฟรมและบีบขนาดให้เหลือไม่เกิน ~300 KB, ใช้ภาพนิ่งเป็นค่าเริ่มต้น และให้เล่นเฉพาะเมื่อผู้ใช้ไม่ได้ตั้ง prefers-reduced-motion

2. หน้าแรกโหลดข้อมูลทั้งหมดของทุกวิชาทุกครั้ง

loadCoursesWithGrades() อ่านทุกวิชา → ทุกห้อง → นักเรียนทุกคน + คะแนนทุกแถว จาก Firestore ทุกครั้งที่เปิดหน้า
วนทีละวิชาด้วย for + await ต่อกัน (waterfall) จึงช้าลงตามจำนวนวิชา และเสียจำนวน read เป็นค่าใช้จ่ายด้วย

## แคชข้อมูลรายวิชา (หน้าแรก + หน้ารายงาน)

`loadCoursesWithGrades()` ใน `js/dashboard.js` เก็บผลไว้ใน `AppState.courseDataCache` (อายุ 5 นาที) และโหลดวิชา/ห้องแบบขนาน
**กติกาสำหรับโค้ดใหม่:** ทุกครั้งที่เขียนข้อมูลวิชา/ห้อง/นักเรียน/คะแนน/โครงสร้าง/เกณฑ์เกรดลง Firestore ให้เรียก
`invalidateCourseData(courseId)` (ล้างเฉพาะวิชานั้น) หรือ `invalidateCourseData()` (ล้างทั้งหมด เมื่อรายการวิชาเปลี่ยน เช่น สร้าง/เก็บเข้าคลัง/ลบ)
บังคับโหลดใหม่ทั้งหมดได้ด้วย `loadCoursesWithGrades({ force: true })`

## กติกาคะแนน/เกรด (แก้ความถูกต้องของข้อมูล)

- **ผลรวมคะแนนต้องผ่าน `roundScore()` เสมอ** (`js/utils.js`) และ `calcGrade()` ปัดให้เองแล้ว — กันเลขทศนิยมลอยตัวทำให้เกรดตกผิดที่ขอบเกณฑ์ (เช่น 50 กลายเป็น 49.99999999999999)
- **ช่องคะแนนที่ว่าง = ไม่มีฟิลด์ในฐานข้อมูล** (ไม่ใช่ 0) เพื่อแยก "ยังไม่กรอก" ออกจาก "ได้ 0" · ล้างช่องจะลบฟิลด์ด้วย `FieldValue.delete()`
- **คะแนนเกินคะแนนเต็มจะถูกปรับเป็นคะแนนเต็มทั้งตอนพิมพ์และตอนวาง** (ถ้าต้องการให้โบนัส ให้เพิ่มคะแนนเต็มที่หน้าโครงสร้างวิชา)
- **วางจาก Excel**: ใช้ `parseDelimitedText(text, { keepBlank: true })` คงตำแหน่งแถว/ช่องว่าง · ช่องว่าง = ล้างช่อง · ข้อความที่ไม่ใช่ตัวเลขจะถูกข้าม
- **บันทึกพลาด** จะลองซ้ำอัตโนมัติ 4 ครั้ง ถ้ายังพลาดจะแสดง "บันทึกไม่สำเร็จ N ช่อง — แตะเพื่อลองใหม่" และเตือนก่อนปิดหน้า
- `parseDelimitedText` รองรับ CSV ที่ครอบช่องด้วย `"..."`
- ชุดทดสอบ: `tests/score-logic.test.js`
